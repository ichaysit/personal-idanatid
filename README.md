# Ichay Sitbon — site personnel / אתר אישי

Page d'accueil pour présenter mes services de création de sites web, mes offres et mes tarifs.
Le site s'ouvre en hébreu ; un bouton permet de passer en français (`?lang=fr` ouvre directement la version française).

דף הבית שלי: שירותי בניית אתרים, חבילות ומחירים. האתר נפתח בעברית, ויש כפתור למעבר לצרפתית.

## Contenu du dépôt

- `index.html` : tout le site (HTML, CSS et JavaScript dans un seul fichier, sans dépendance à installer).

## Modifier mes informations

En bas de `index.html`, le bloc `CONFIG` contient le nom (hébreu et français), le numéro WhatsApp et l'e-mail.
Le numéro de téléphone et l'e-mail affichés dans la section Contact sont aussi dans le HTML (cherchez `coords`).

## Mise en ligne

Le site est publié avec GitHub Pages depuis la branche `main`.
